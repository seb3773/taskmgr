Task Manager is a lightweight, modern native task and system resource monitor designed specifically for Q4OS / Trinity Desktop Environment (TDE).

Key Features:

  • Process Management: Complete process control (tree view, priority adjustment, signals, clean termination, PSS/RSS memory details).
  • Performance Graphs: Real-time monitoring metrics for CPU (overall & per-core), RAM, Swap, Disks, Network, and GPU.
  • Startup Applications: Manage autostart applications (standard XDG entries and native TDE conditions).
  • Services Management: Monitor and control systemd system services.
  • High Performance: Minimal memory footprint, zero CPU overhead, native TQt3/TDE integration.
