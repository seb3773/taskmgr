Task Manager v1.1

Lightweight, modern task and system resource monitor for Trinity Desktop Environment (TDE) & Linux systems.

🚀 Method 1: Add the APT Repository (Recommended)

Add the official repository to your system to receive regular automated updates via apt: 

echo "deb [trusted=yes] https://seb3773.github.io/taskmgr/ stable main" | sudo tee /etc/apt/sources.list.d/taskmgr.list
sudo apt update
sudo apt install taskmgr

Compatible with Debian, Q4OS, Devuan, Ubuntu, Linux Mint and derivatives.

📦 Method 2: Standalone & Direct Downloads

Choose the format best suited for your setup:

📥 Download Q4OS Installer (.qsi) 📦 Download Debian Package (.deb) 🐧 Download AppImage (Portable)

* Note: The Q4OS installer (.qsi) automatically configures the APT repository during installation for future updates.

✨ Key Features

⚡ Process Tree & Control

Tree hierarchy, signals, clean termination, priority adjustment, and detailed memory analysis (PSS, RSS, VSZ).

📊 Real-Time Graphs

Smooth real-time graphs for CPU (overall & per-core), RAM, Swap, Disk throughput, Network, and GPU engines.

🚀 Startup Manager

Manage autostart applications for both standard XDG entries and native Trinity Desktop (TDE) conditions.

⚙️ Services Management

Inspect, start, stop, restart, enable, or disable systemd system services directly with root elevation support.
